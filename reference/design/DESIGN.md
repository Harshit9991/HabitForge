# HabitForge visual contract

This repository preserves the forge-inspired visual language as a runtime-owned contract:

- layered near-black surfaces with crisp, low-contrast borders;
- frost-cyan telemetry and completion states with restrained amber accents;
- compact squared controls and monospace metadata;
- Plus Jakarta Sans-style body typography with a deterministic system fallback;
- one responsive composition, with desktop header navigation and mobile bottom navigation.

The original static archive was not present in the checkout. This contract records the implementation baseline so missing network assets or prototype files cannot change layout or behavior.
